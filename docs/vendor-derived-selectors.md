# Vendor-derived selector inventory

The repository contains no raw extracted bundle or executable. Compatibility still requires small source-derived selectors:

- the durable planner replaces one minified function (about 270 source characters);
- pointer gaze uses two method-boundary names and one short hover expression, replacing the method body with original enhancer code;
- sleep uses six short renderer fragments, nine component fragments, and one overlay property fragment;
- manifests store four or five target-entry hashes, depending on the build, plus short counted structural fingerprints.

The private prototype's multi-kilobyte exact mascot-function preimage was deliberately removed. Public sleep patching now performs counted narrow edits only after the entire source ASAR and target entry hashes match. Builds 9922, 10789, and 11431 add separate sets of similarly narrow, version-specific selectors; none adds an extracted function or bundle. The physical-gaze bridge remains a compact replacement method because that runtime method is the verified handoff point to Codex's existing selector. This inventory is technical disclosure, not a legal conclusion. Review is still recommended before publication.
