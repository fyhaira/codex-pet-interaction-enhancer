# Public/private boundary

This repository contains original enhancer code, hashes, narrow structural selectors, public documentation, and generated geometric fixtures. It must not contain copied applications, executables, raw vendor bundles, patched ASARs, user profiles, frozen checkpoints, diagnostic traces, screenshots, credentials, private character art, or machine-specific evidence.

Local-only inputs and outputs belong under ignored `local/`. The public audit and intended-file manifest are release gates. Private development history may inform a concise design decision but is never copied wholesale.
