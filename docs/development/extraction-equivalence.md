# Public extraction equivalence

The public repository was extracted selectively from the accepted private Phase 3 toolkit.

- `durable-states`: applying private and public transforms to the frozen Phase 1 bundle produced byte-identical target output.
- `sleep`: applying the private full-preimage transform and public counted-fragment transform to the frozen Phase 2 bundle with identical generic capability data produced byte-identical output for all three target entries.
- `pointer-gaze`: the public method was reformatted and stripped of private lab wording; deterministic tests cover all sixteen sectors, visual-centre geometry, V1 fallback, hover priority, activation/exit radii, boundary hysteresis, and precedence contract. Constants and message path are unchanged.
- public configuration replaces the private pet capability and artwork with the generated geometric fixture; this intentionally changes embedded asset bytes, not runtime semantics.
- build 9922 uses independent feature-local transform profiles. Its private QA candidate passed structural, integrity, signing, and behavior-model regression tests; the public transform profile then passed against the same installed source. Build-8881 durable and sleep outputs remained byte-identical after profile dispatch was introduced.
- build 10789 uses a third exact manifest and independent feature-local profiles. Its private QA candidate passed source gates, transform assertions, ASAR-integrity verification, deep signing verification, behavior-model regression tests, the seven-step live lifecycle check, and a full 360-degree gaze sweep before daily-use promotion.

The currently installed Codex version is not used as a substitute compatibility target. Local integration is skipped unless `CODEX_SOURCE_APP` points to the exact manifested build.
