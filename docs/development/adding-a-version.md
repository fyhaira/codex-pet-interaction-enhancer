# Adding support for a Codex version

Work from a disposable copy. Record version/build/platform/architecture and source hashes; locate semantic targets by structure; compare each transform; add a new manifest rather than overwriting an old one; add a dedicated transform profile when syntax or minified names differ; run pure, fixture, compatibility, and local integration tests; manually verify all Phase 1–3 lifecycles. Never accept a version based only on a renamed minified symbol. A reviewed source hash and counted selectors are mandatory. Verify the raw ASAR-header hash independently from the whole-file artifact hash, and inspect whether that Electron build also enforces an embedded framework integrity digest before choosing the signing path.
