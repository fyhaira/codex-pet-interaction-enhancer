# Contributing

Keep changes inside established feature boundaries, preserve fail-closed validation, and run `npm run check`. Never commit copied Codex material, local app copies, private pets, secrets, or raw diagnostic logs. Version ports require a new manifest and evidence. Feature changes require separate design review; this developer preview currently preserves only the documented Phase 1–3 semantics.

Bug reports and detailed technical issue reports are welcome. Code contributions and pull requests should be submitted only when explicitly invited or after prior discussion with the project owner. Before an invited contribution, regenerate or verify the fixture if its generator changed and explain every vendor-derived selector added or enlarged.

Submitting an issue or invited contribution does not authorize redistribution of this project under different terms. Any accepted code contribution will be incorporated under the project's current Personal Use License. Contributors must have the right to submit their material and must agree to that licensing before it can be accepted. No contributor license agreement is currently required; the owner may request written confirmation for a proposed contribution.
