# Contributing

Keep changes inside established feature boundaries, preserve fail-closed validation, and run `npm run check`. Never commit copied Codex material, local app copies, private pets, secrets, or raw diagnostic logs. Version ports require a new manifest and evidence. Feature changes require separate design review; this developer preview currently preserves only the documented Phase 1–3 semantics.

Before opening any future contribution, regenerate/verify the fixture if its generator changed and explain every vendor-derived selector added or enlarged.

Unless explicitly stated otherwise, contributions intentionally submitted for inclusion are accepted under the repository's Apache-2.0 license. Do not submit material you do not have the right to contribute.
